# ADI UNR Lab Kit — Summary and Kit-vs-Doc Corrections

- Source: ADI lab kit extracted at `Handoff/.tmp/unr_kit/unr/` (design: `timer`, project `lab_unr`).
- The kit is a training example only; it uses OLD tool versions (`jg/adi/2021.12-p001`, `adsim/adi/6.06`, `xlm/adi`, `mdv/adi`; commented `incisive 15.20`, `xlm 17.04`).
- This skill uses the installed Jasper 2025.09 docs (`doc_reference.md`); every kit item below was checked against them.
- Do NOT copy timer-specific names (`tmr_tb`, `u_timer`, `PCLK`, `clkmux_x2_box`, ...) into project collateral — the templates use `<ip>`, `<tb_top>.<inst>`.

## Kit sim.setup UNR Block (verbatim names, values generalised)

| Line | Meaning |
|------|---------|
| `UNR_FML_COVERAGE : b:e:t` | coverage types for UNR (block, expression, toggle) |
| `UNR_FML_COVDB : <results>/latest_regr/coverage/cov_work/scope/merged_data` | merged sim coverage test dir (`<covwork>/<covscope>/<covtest>`) |
| `UNR_EXTRA_COMPILE_OPTIONS : -covfile <ccf>` | coverage config passed to the UNR compile |
| `UNR_FML_INSTTOP : <tb_top>.<inst>` | formal top = DUT instance below the TB |
| `UNR_FML_TCL_FILE : <path>/jg_unr.tcl` | user UNR TCL |
| `UNR_FML_BBLIST : <path>/unr.bb` | modules to black-box |
| `!UNR_SIM_COMPLETE_FLAG : Simulation Passed!` | `!` = negated prefix → `SIM_COMPLETE_FLAG` set only when NOT running `-unr`; it is NOT a UNR setting |

## Kit vs Doc (corrections applied in this skill)

| # | Kit item | Doc (2025.09) | Correction |
|---|----------|---------------|------------|
| K1 | `check_unr -setup -coverage all` | D2/D1 syntax: `-setup [-task]` only; `-coverage` belongs to `check_unr -init` (before elaborate; generated by xrun from `-jg_coverage`) | use `check_unr -setup`; select types with `-jg_coverage` / `UNR_FML_COVERAGE` (D2 example line shows `-setup -coverage` — doc-internal inconsistency) |
| K2 | `database -init_unicov` (no `-app`) at top of TCL | D2: `-init_unicov` only initialises export; `-app` default `all` = all apps EXCEPT UNR; export works without it; periodic export: `database -init_unicov -app unr -interval <t>` before setup (D1) | drop it, or use `-app unr -interval <t>` for periodic export |
| K3 | `#check_unr -covgen -force` | no `-covgen` in D2 `check_unr` syntax | removed |
| K4 | `timer/unr/unr.tcl`: `define effort`, `prove`, `assertion -summary -time` | legacy IEV commands; `define` / `assertion` are not Jasper commands in D2 | `check_unr -prove [-time_limit] [-engine_mode]`, `check_unr -list -type ...`, `report -summary -task unr` |
| K5 | jg 2021.12-p001, "do not change the jg and xlm versions" | D1 Xcelium Version Dependency: Xcelium ≥ 22.07.a071 incompatible with Jasper ≤ 2022.06 FCS | use the installed Jasper (2025.09) with a matching Xcelium; record versions |
| K6 | UNR compile gets only `-covfile nccov.txt`; sim used `cov_generic.ccf` + `nccov.txt` | D1 `-covfile`: use the same coverage options incl. `-covfile` as the simulation; D1 Assumptions: same options for all merged DBs | pass every sim ccf to the UNR compile, in the same order |
| K7 | toggle/glitch strobe `10fs` (cov_generic) vs `5 ns` (nccov) in the same compile | D1 `-covfile` note: expected `set_toggle_strobe 1fs` or `set_toggle_scoring -regeot`, plus `set_glitch_strobe`; D6 `covfile.cf` | one consistent glitch setting in sim and UNR; changing it requires re-running sim |
